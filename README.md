# Interview Box — PWA

An installable, offline-first rewrite of Interview Box v7 (one 3.25 MB HTML file) as a
real PWA: 1,950 questions, four languages, audio, speaking coach, mock interviews, JD prep
and an SQL Lab — all working with no signal.

Built from the v7 sources that no longer exist: the bank, the 260-term audio dictionary,
the modern-register lexicons, the prompt rules, the 30 SQL exercises and the speaking-coach
content are **extracted from the shipped v7 file itself** by `scripts/extract-v7.mjs`.

## 📖 Read this first

**[`INTERVIEW_GUIDE.md`](./INTERVIEW_GUIDE.md)** — how to run it, the architecture and data flow, a
full feature inventory, the v7 → PWA migration, the bugs found and how, what was
deliberately skipped, trade-offs, and interview Q&A you can prepare with.

## Quick start

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # production build + service worker
npm run preview      # serve the build
npm test             # 37 unit tests
node e2e/smoke.mjs   # 39 browser checks against the build
node e2e/offline.mjs # proves the app works with the network cut
```

## Where things are

| Path                            | What it is                                                                 |
| ------------------------------- | -------------------------------------------------------------------------- |
| `src/lib/types.ts`              | Every domain type. `code` keeps the v7 IDs so old progress still matches.  |
| `src/lib/db.ts`                 | Dexie schema — 14 tables, offline-first.                                   |
| `src/lib/seed.ts`               | Loads the bank into IndexedDB and builds the search haystack.              |
| `src/lib/lang.ts`               | Modern-register lexicons, Roman Urdu normaliser, term protection.          |
| `src/lib/text.ts`               | `bidiFix` for RTL, `enSay` for TTS, byte-safe `splitText`, word alignment. |
| `src/lib/speech.ts`             | Web Speech synthesis + recognition, with the v7 reliability fixes.         |
| `src/lib/translate.ts`          | AI → free machine translation → pack → setup card. Never a dead end.       |
| `src/lib/ai.ts`, `providers.ts` | One gateway; server mode (Laravel) or direct provider keys.                |
| `src/lib/features.ts`           | Explain, grade, interview, JD pack, speaking feedback, agent, CV match.    |
| `src/lib/fsrs.ts`               | Spaced repetition (Weak / Okay / Solid).                                   |
| `src/lib/sqllab.ts`             | sql.js on the **asm.js** build — no WASM fetch, no CSP trouble.            |
| `src/lib/backup.ts`             | Backup/restore, including the v7 backup format.                            |
| `src/lib/sync.ts`               | Outbox + delta sync to a Laravel server when one is set.                   |
| `src/features/*`                | The 12 screens.                                                            |
| `public/data/*.json`            | Generated by the extractor. Do not hand-edit.                              |

## What was carried over from v7

Every screen, the whole question bank with stable IDs, the four languages and the register
rules, the audio dictionary and listen modes, the player with think time / memorise mode /
auto-next / sleep timer / wake lock, the speaking coach's six tabs, mock interviews with AI
grading, JD prep, SQL Lab, Learn, Downloads with study-pack export, and the v7 backup format.

Fixed along the way, each found by a test rather than by reading:

- the duplicated `puter` key in v7's `PROV` object (the second declaration silently won);
- `bidiFix` wrapping the literal text "code" inside the `<code>` tag it had just created;
- a Dexie index named `techs` while the field is `t`, so tech filters always returned nothing;
- the dictionary and lexicon pairs being pipe-joined strings, which broke `dict()` and every
  Roman Urdu spelling;
- a circular import between `ai.ts` and `providers.ts` that crashed the app on boot;
- `splitText` failing on text with no spaces, which would have blown the prompt limit on a
  minified transcript.

## AI: two ways to run it

- **Server (recommended).** Point Progress → AI Connect at your Laravel API. Keys stay on the
  server; the browser holds none.
- **Client.** Your own provider key, stored only in `localStorage['ibx-keys']` and never
  included in a backup. Works with no backend at all.

Without AI the library, filters, topics, JD offline analysis, flashcard mocks, SQL Lab,
English audio and every saved translation keep working.

## Not implemented here

Neural server audio, cloud STT, phoneme-level pronunciation scoring, voice cloning, semantic
search and the admin panel need the Laravel + Python services from the 2.0 plan. The client
already speaks the API shape they will use.
