INTERVIEW BOX — LAPTOP

Why: sign-in windows (email account, OpenRouter) only work when the app is opened from a web address.
Opening interview-box.html directly from Downloads (file://) blocks them — that is why AI did not work.

Start (one double-click, keep the small window open):
  Windows : Start Interview Box (Windows).bat
  Mac     : Start Interview Box (Mac).command   (first time: right-click › Open)
  Linux   : bash start-interview-box-linux.sh

The app opens at http://localhost:8765/interview-box.html (only your computer can reach it).
Then: Sign in with email › "Get my phone link" › open that https link on your phone and sign in with the same email.
